# La connaissance

Page principale du portail qui relie les cours de mathématiques et de physique et réserve une place aux prochaines disciplines.

## Ouvrir le portail

Ouvre `index.html` dans un navigateur. Les liens mènent aux catalogues des matières. Aucun serveur ni installation n’est nécessaire.

- `cours-mathematiques/` : dépôt Git indépendant du cours de mathématiques.
- `cours-physique/` : catalogue et leçons de physique.
