Les limites
de fonctions

Une limite décrit le comportement d’une fonction près d’un point ou très loin sur l’axe. Elle aide à comprendre les asymptotes, les valeurs interdites et l’allure générale d’une courbe.

COURS COMPLETLECTURE · 10 MINFONCTIONS RÉELLES

01 / L’IDÉE DE LIMITE

Comprendre une limite

Étudier la limite de f(x) quand x tend vers un nombre a, c’est observer les valeurs de f(x) lorsque x se rapproche de a. On ne demande pas forcément ce que vaut f(a) : la fonction peut même ne pas être définie en a.

LIMITE FINIE EN alimx → a f(x) = L

Cette écriture signifie que les valeurs de f(x) se rapprochent autant que l’on veut de L quand x se rapproche de a. Par exemple, si f(x) = x + 2, alors quand x tend vers 3, f(x) tend vers 5.

On peut aussi étudier une limite à gauche, notée x → a−, ou à droite, notée x → a+. Les deux comportements peuvent être différents. Pour f(x) = 1 / (x − 2), quand x approche 2 par la gauche, le dénominateur est négatif et proche de zéro : la fonction tend vers −∞. Par la droite, elle tend vers +∞.

Limite et valeur de la fonction

Une limite décrit un comportement autour d’un point, pas nécessairement la valeur de la fonction en ce point. Par exemple, (x² − 1) / (x − 1) n’est pas défini en 1, mais sa limite quand x → 1 existe.

02 / QUAND x S’ÉLOIGNE

Les limites à l’infini

Quand x devient très grand en valeur absolue, les termes d’une expression n’ont pas tous la même importance. Pour un polynôme, le terme de plus haut degré finit par dominer les autres.

TERMES DOMINANTSQuand |x| grandit, x3 domine x2, qui domine x, qui domine 1.

Ainsi, pour f(x) = 2x3 − 5x + 1, le terme dominant est 2x3. Quand x → +∞, ce terme tend vers +∞, donc f(x) tend vers +∞. Quand x → −∞, 2x3 tend vers −∞, donc f(x) aussi.

Quelques limites de référence

x → +∞

Si n > 0, alors xn → +∞.

x → −∞

Pour une puissance paire, xn → +∞ ; pour une puissance impaire, xn → −∞.

x → ±∞

Pour n > 0, 1 / xn → 0. La fraction se rapproche de zéro sans nécessairement l’atteindre.

Le cas d’un quotient de polynômes

Pour une fraction rationnelle, compare les degrés du numérateur et du dénominateur. À l’infini, les termes de plus haut degré dominent. Si les degrés sont égaux, la limite est le quotient des coefficients dominants. Si le degré du numérateur est plus petit, la limite vaut zéro.

(3x2 + x) / (2x2 − 1)→ 3 / 2 quand x → ±∞

Si le degré du numérateur est plus grand, la fraction peut tendre vers l’infini ; il faut alors étudier le signe et l’écart des degrés.

03 / COMBINER DES LIMITES

Les règles de calcul

Quand les limites des fonctions u et v sont connues, on peut souvent en déduire la limite de leur somme, produit ou quotient. Les règles suivantes s’appliquent lorsque les opérations ont un sens ; les cas indéterminés demandent une étude supplémentaire.

LIMITE FINIE ET SOMMESi u → L et v → M, alors u + v → L + M.
SOMME

Une limite finie s’ajoute terme à terme. Une quantité qui tend vers +∞, additionnée à un nombre fixe, tend encore vers +∞.

PRODUIT

On multiplie les limites finies. Le produit d’une quantité qui tend vers +∞ par une constante positive tend vers +∞ ; si la constante est négative, il tend vers −∞.

QUOTIENT

Si le dénominateur tend vers une limite non nulle M, le quotient tend vers L / M. Si le dénominateur tend vers zéro, il faut étudier son signe.

Exemple : quand x → 2, x² + 3x tend vers 2² + 3 × 2 = 10. Pour les polynômes, on peut remplacer directement x par la valeur vers laquelle il tend.

Autre exemple : quand x → +∞, (5x + 1) / (x − 2) tend vers 5, car les deux polynômes sont de même degré et le quotient des coefficients dominants vaut 5 / 1.

04 / QUAND LA RÈGLE NE SUFFIT PAS

Les formes indéterminées

Une forme indéterminée signifie que les règles usuelles ne permettent pas, à elles seules, de conclure. Ce n’est pas le résultat de la limite : c’est un signal qu’il faut transformer ou simplifier l’expression.

FORME INDETERMINÉE∞ − ∞
FORME INDETERMINÉE0 / 0
FORME INDETERMINÉE∞ / ∞
FORME INDETERMINÉE0 × ∞

Exemple : lever une forme 0 / 0

Quand x → 1, le numérateur x² − 1 tend vers zéro et le dénominateur x − 1 aussi. On obtient la forme 0 / 0 : impossible de conclure tout de suite. On factorise le numérateur :

FACTORISER, PUIS SIMPLIFIER POUR x ≠ 1(x2 − 1) / (x − 1) = (x − 1)(x + 1) / (x − 1) = x + 1

Pour x ≠ 1, la fraction vaut donc x + 1, qui tend vers 2 lorsque x → 1. La limite cherchée est 2, même si la fraction de départ n’est pas définie en 1.

Les bons réflexes

  • Pour une différence de polynômes, factorise par le terme dominant ou mets les expressions au même dénominateur.
  • Pour une fraction en 0 / 0, factorise et simplifie, ou utilise une identité remarquable.
  • Pour une fraction en ∞ / ∞, divise le numérateur et le dénominateur par la plus grande puissance de x.
  • Ne simplifie jamais en un point où le dénominateur est nul sans préciser que l’égalité vaut pour les valeurs autorisées autour de ce point.

05 / LIRE LA COURBE

Les asymptotes

Une asymptote est une droite dont la courbe se rapproche indéfiniment. Les limites permettent de les repérer et d’écrire leur équation.

Asymptote verticale

Si f(x) tend vers +∞ ou −∞ quand x → a (à gauche, à droite ou des deux côtés), la droite d’équation x = a est une asymptote verticale. Par exemple, pour f(x) = 1 / (x − 2), la droite x = 2 est une asymptote verticale.

Asymptote horizontale

Si f(x) → L quand x → +∞ (ou quand x → −∞), la droite y = L est une asymptote horizontale dans cette direction. Comme (3x² + x) / (2x² − 1) → 3 / 2, sa courbe admet la droite y = 3 / 2 comme asymptote horizontale aux deux infinis.

Attention

Une fonction peut avoir des limites différentes en +∞ et en −∞. Il faut donc étudier séparément les deux directions avant de conclure.

06 / S’ENTRAÎNER

À toi de jouer

Commence par identifier la situation : substitution directe, comportement à l’infini, ou forme indéterminée ? Ouvre ensuite la correction pour comparer ta démarche.

ACalculer limx → 2 (x² + 3x − 1).Voir la correction

Un polynôme est défini et continu en 2 : on remplace x par 2. 2² + 3 × 2 − 1 = 4 + 6 − 1 = 9. La limite vaut 9.

BCalculer limx → 1 (x² − 1) / (x − 1).Voir la correction

La substitution donne 0 / 0, une forme indéterminée. Pour x ≠ 1, on factorise : (x² − 1) / (x − 1) = x + 1. La limite de x + 1 en 1 vaut 2. La limite vaut 2.

CCalculer limx → +∞ (4x² − x) / (2x² + 5).Voir la correction

Les degrés du numérateur et du dénominateur sont égaux. Le quotient tend vers le quotient des coefficients dominants : 4 / 2 = 2. La limite vaut 2.

DQuelle est l’asymptote verticale de f(x) = 3 / (x + 4) ?Voir la correction

Le dénominateur s’annule en x = −4. À proximité, la fonction devient infiniment grande en valeur absolue. La droite x = −4 est l’asymptote verticale.
