01 / RECONNAÎTRE

La forme générale

Une expression du second degré, aussi appelée trinôme du second degré, s’écrit sous la forme :

FORME DÉVELOPPÉE RÉDUITEf(x) = ax2 + bx + c   avec a ≠ 0

Les nombres a, b et c sont les coefficients. Le coefficient a ne peut pas être nul : si a = 0, il ne reste plus de terme en x au carré et l’expression n’est plus du second degré.

Pour lire les coefficients, il faut d’abord remettre l’expression dans l’ordre x², x, puis terme constant. Par exemple, dans 3x2 − 5x + 2, on a a = 3, b = −5 et c = 2. Attention : le signe fait partie du coefficient.

Objectif du chapitre

Résoudre ax2 + bx + c = 0, factoriser le trinôme lorsque c’est possible dans ℝ, puis déterminer où il est positif ou négatif.

02 / RÉSOUDRE UNE ÉQUATION

Le discriminant et les racines

Pour résoudre ax2 + bx + c = 0, on calcule d’abord le discriminant, noté Δ (delta). Il résume l’information nécessaire pour savoir combien de solutions réelles possède l’équation.

CALCUL DU DISCRIMINANTΔ = b2 − 4ac
Δ > 0

Deux solutions réelles distinctes. Le trinôme s’annule en deux valeurs différentes, appelées racines.

Δ = 0

Une solution réelle double. Les deux racines se confondent en x0 = −b / 2a.

Δ < 0

Aucune solution réelle. Le trinôme ne s’annule jamais sur ℝ.

Ce que montrent les paraboles

Le coefficient a indique le sens d’ouverture : si a > 0, les branches montent ; si a < 0, elles descendent. Le discriminant indique combien de fois la courbe coupe l’axe des abscisses : deux fois si Δ > 0, une fois si Δ = 0, jamais si Δ < 0.

Quand Δ est positif

Si Δ > 0, les deux solutions sont obtenues avec la formule suivante. Le signe « ± » signifie que l’on effectue un calcul avec « + », puis un autre avec « − ».

PREMIÈRE RACINEx1 = (−b − √Δ) / 2a
SECONDE RACINEx2 = (−b + √Δ) / 2a

Exemple : deux racines

Résolvons x2 − 5x + 6 = 0. Ici, a = 1, b = −5 et c = 6. On calcule Δ = (−5)2 − 4 × 1 × 6 = 25 − 24 = 1. Comme Δ > 0, il y a deux solutions :

x1 = (5 − 1) / 2 = 2x2 = (5 + 1) / 2 = 3Solutions : {2 ; 3}

Exemple : racine double ou aucune racine

Pour −3x2 + 12x − 12 = 0, on trouve Δ = 122 − 4 × (−3) × (−12) = 0. L’unique solution est x0 = −12 / (2 × −3) = 2.

Pour 2x2 + 2x + 3 = 0, on trouve Δ = 22 − 4 × 2 × 3 = −20. Comme le discriminant est négatif, l’équation n’a aucune solution réelle.

Vérification utile

Quand tu as trouvé des racines, remplace x dans l’équation de départ. Une racine doit rendre le trinôme égal à zéro.

03 / PASSER AUX FACTEURS

Relier racines et factorisation

Une racine r est une valeur pour laquelle f(r) = 0. Cela signifie que le facteur (x − r) apparaît dans la factorisation du trinôme. Le discriminant indique précisément quelle forme de factorisation utiliser.

SI Δ > 0 : DEUX RACINES x₁ ET x₂ax2 + bx + c = a(x − x1)(x − x2)
SI Δ = 0 : UNE RACINE DOUBLE x₀ax2 + bx + c = a(x − x0)2

Dans l’exemple précédent, les racines de x2 − 5x + 6 sont 2 et 3. On peut donc écrire x2 − 5x + 6 = (x − 2)(x − 3). Développer cette forme redonne bien le trinôme de départ.

Si Δ < 0, il n’y a pas de racine réelle : le trinôme ne peut pas se factoriser en produit de deux facteurs du premier degré à coefficients réels. Cela n’empêche pas de connaître son signe : il est toujours celui de a.

À retenir

Résoudre l’équation, c’est trouver les racines. Factoriser, c’est réécrire l’expression à l’aide de ces racines. Ces deux résultats serviront ensuite à étudier le signe.

04 / ÉTUDIER LE SIGNE

Résoudre une inéquation

Une inéquation demande pour quelles valeurs de x le trinôme est positif, négatif, ou nul. La règle de signe se lit à partir des racines et du signe de a. Elle vient du fait que, dans la forme factorisée, le signe change à chaque racine simple.

Deux racines distinctes : Δ > 0

On range d’abord les racines dans l’ordre x1 < x2. À l’extérieur de l’intervalle entre elles, le trinôme a le signe de a. Entre les deux racines, il a le signe contraire. Aux racines, il vaut zéro.

Si a > 0, le signe est donc + / − / +. Si a < 0, il est − / + / −.

Une racine double : Δ = 0

Le trinôme s’écrit a(x − x0)2. Un carré est toujours positif ou nul : le trinôme garde donc le signe de a des deux côtés de x0, et s’annule seulement en ce point.

Aucune racine réelle : Δ < 0

Le trinôme ne s’annule jamais et ne change pas de signe. Il garde partout le signe de son coefficient a.

Exemple détaillé

Résolvons 2x2 − 8x + 6 ≤ 0. On factorise : 2x2 − 8x + 6 = 2(x − 1)(x − 3). Les racines sont 1 et 3, et le coefficient directeur du terme de degré 2 vaut a = 2 > 0. Le signe est donc positif à l’extérieur des racines et négatif entre elles.

On cherche les valeurs où l’expression est négative ou nulle. Les deux racines sont donc incluses : l’ensemble des solutions est [1 ; 3].

Le signe de l’inégalité compte

Pour ≤ ou ≥, on inclut les racines quand elles annulent le trinôme. Pour < ou >, on les exclut.

05 / SUIVRE LES ÉTAPES

Une méthode qui marche

Pour éviter de te perdre dans les calculs, garde toujours le même ordre. L’étude du signe ne commence qu’une fois les racines calculées et rangées.

  1. Mettre l’expression sous forme développée réduite.Repère a, b et c, sans oublier leurs signes, et vérifie que a ≠ 0.
  2. Calculer le discriminant.Écris Δ = b2 − 4ac en remplaçant chaque coefficient avec ses parenthèses.
  3. Conclure sur le nombre de racines.Compare Δ à zéro avant d’appliquer une formule.
  4. Calculer puis ordonner les racines.Quand il y en a deux, écris clairement x1 < x2.
  5. Établir le signe du trinôme.Commence et termine par le signe de a ; entre deux racines simples, le signe est contraire.
  6. Lire l’ensemble solution.Respecte le symbole de l’inégalité et inclus les racines seulement si l’inégalité est large (≤ ou ≥).

Les erreurs à éviter

  • Oublier un signe : si b = −5, alors b² = (−5)² = 25.
  • Confondre une racine et son facteur : la racine 3 donne le facteur (x − 3), pas (x + 3).
  • Inverser le signe à l’extérieur : à l’extérieur des racines, c’est le signe de a ; à l’intérieur, son contraire.
  • Inclure une borne à tort : une racine n’appartient pas à la solution d’une inégalité stricte si elle annule l’expression.
  • Oublier le cas Δ < 0 : aucune racine réelle ne signifie pas « aucun signe » ; le trinôme garde le signe de a.

06 / S’ENTRAÎNER

À toi de jouer

Essaie chaque question avant d’ouvrir la correction. Pour les inéquations, écris d’abord le signe du trinôme, puis traduis le signe demandé en intervalles.

ARésoudre x2 + 2x − 8 = 0.Voir la correction

On a a = 1, b = 2, c = −8. Alors Δ = 22 − 4 × 1 × (−8) = 36, donc √Δ = 6. Les racines sont (−2 − 6) / 2 = −4 et (−2 + 6) / 2 = 2. Solutions : {−4 ; 2}.

BRésoudre x2 − 6x + 9 ≥ 0.Voir la correction

Le discriminant vaut Δ = 36 − 36 = 0. La racine double est x0 = 3, et le trinôme s’écrit (x − 3)2. Un carré étant toujours positif ou nul, l’inégalité est vraie pour tout réel. Solutions : ℝ.

CRésoudre −2x2 + 2x + 4 > 0.Voir la correction

On factorise : −2x2 + 2x + 4 = −2(x − 2)(x + 1). Les racines sont −1 et 2, et a = −2 < 0. Le trinôme est positif entre les racines. L’inégalité est stricte, donc les bornes sont exclues. Solutions : ]−1 ; 2[.

DRésoudre x2 + 4x + 7 < 0.Voir la correction

Le discriminant vaut Δ = 42 − 4 × 1 × 7 = −12. Il est négatif, donc le trinôme garde le signe de a = 1 : il est toujours strictement positif. Il ne peut donc jamais être inférieur à zéro. Solutions : ∅.
